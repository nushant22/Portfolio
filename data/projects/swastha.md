# Swastha - Multi-Role Telemedicine Platform

**Type**: Final Year Capstone Project  
**Role**: Project Coordinator & Full-Stack Developer  
**Tech Stack**: React, Vite, Node.js, Express, Prisma, PostgreSQL, Socket.IO, WebRTC, Python ML

## Overview

Swastha is a comprehensive telemedicine platform that enables remote healthcare delivery through video consultation, appointment management, and AI-powered disease prediction.

## Key Features

### Video Consultation System
- Real-time video calls between patients and doctors using WebRTC
- Socket.IO for signaling and connection management
- High-quality audio/video streaming

### Payment Integration
- Integrated Khalti and eSewa payment gateways
- Secure payment processing for consultations
- Transaction history and receipts

### AI Disease Prediction
- Python-based ML microservice
- Symptom analysis and disease prediction
- FastAPI backend for ML model serving

### Multi-Role System
- Patient portal with appointment booking
- Doctor dashboard with patient management
- Admin panel for system oversight

## Technical Highlights

- Full-stack architecture with React frontend and Node.js backend
- Prisma ORM for type-safe database operations
- Real-time features using WebSocket connections
- Microservices architecture for ML components
- Responsive design for mobile and desktop
