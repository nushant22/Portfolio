# Portfolio

Personal portfolio website with full-stack capabilities.

## Project Structure

```
Portfolio/
├── .git/              # Git repository root
├── .gitignore         # Git ignore rules
├── README.md          # This file
└── portfolio/         # Main project folder
    ├── frontend/      # Next.js application
    ├── backend/       # FastAPI server
    └── *.md           # Documentation
```

## Getting Started

Navigate to the portfolio folder and follow the setup guide:

```bash
cd portfolio
```

Then see:
- **QUICK_START.md** - Get running in 5 minutes
- **SETUP_GUIDE.md** - Detailed setup instructions
- **FEATURES.md** - Complete feature list
- **COMPLETED.md** - What's been built

## Quick Commands

```bash
cd portfolio

# Setup (first time only)
.\setup-backend.ps1
.\setup-frontend.ps1

# Start development servers
.\start-dev.ps1
```

## Tech Stack

- **Frontend**: Next.js 14, React 18, TypeScript
- **Backend**: FastAPI, PostgreSQL, SQLAlchemy
- **Auth**: JWT with role-based access control

## Features

- 🔐 Role-based authentication (Admin/Editor/Viewer)
- 📝 Blog management system
- 💼 Project showcase
- 👥 User management
- 🔒 Secure JWT authentication
- 📊 RESTful API with auto-generated docs
