# 👋 Start Here

You've cloned the Portfolio repository. Here's what you need to know:

## 📁 Folder Structure

```
Portfolio/           ← You are here (GitHub repo root)
└── portfolio/       ← Navigate here to start
    ├── frontend/    ← Next.js application
    ├── backend/     ← FastAPI server
    └── *.md         ← Documentation
```

## 🚀 Getting Started

### Step 1: Navigate to the portfolio folder
```bash
cd portfolio
```

### Step 2: Read the documentation
- **QUICK_START.md** - Get running in 5 minutes
- **SETUP_GUIDE.md** - Detailed setup instructions
- **FEATURES.md** - What this portfolio can do
- **COMPLETED.md** - What's already built

### Step 3: Setup and run
```bash
# Setup (first time only)
.\setup-backend.ps1
.\setup-frontend.ps1

# Start development servers
.\start-dev.ps1
```

## 📖 Important

**All commands should be run from the `portfolio/` folder**, not from the repository root.

```bash
# Wrong ❌
C:\...\Portfolio> .\setup-backend.ps1

# Correct ✅
C:\...\Portfolio> cd portfolio
C:\...\Portfolio\portfolio> .\setup-backend.ps1
```
