eSewa Reconciliation Engine

Personal Project | 2026

Reconciliation tool that matches an internal ledger against partner and bank statements, using Python, Polars, and Streamlit. Sorted every row into exact, mismatch, and orphan buckets, with a conservation check that fails the run if any rows are lost. Handled Nepal-specific data issues: UTC to NPT date shifts, Bikram Sambat dates, NPR currency formats, and leading-zero loss. Matched about 200,000 rows against about 198,000 in 1.3 seconds, and exported CSV or Excel reports. Added SQLite audit log with SHA-256 file hashes, an airlines reconciliation module with a shared Postgres history, and pytest coverage.
