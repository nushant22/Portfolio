eSewa Reconciliation Engine

Reconciliation tool that matches internal ledger against partner and bank statements using Python, Polars, and Streamlit. Sorts rows into exact, mismatch, and orphan buckets with conservation check. Handles Nepal-specific data: UTC to NPT date shifts, Bikram Sambat dates, NPR currency formats. Matches ~200,000 rows in 1.3 seconds with SQLite audit log and SHA-256 file hashes.
