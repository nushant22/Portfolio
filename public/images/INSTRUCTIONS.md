# Image Instructions

## Profile Photo

Place your profile photo in this directory as `profile.jpg`

The image you provided has been received. Save it to:
```
public/images/profile.jpg
```

## Recommended Specifications

- **Format**: JPG or PNG
- **Size**: 800x800px minimum (square aspect ratio)
- **Quality**: High resolution for retina displays
- **File size**: Under 500KB (optimized for web)

## How to Add

1. Save your profile photo as `profile.jpg` in the `public/images/` folder
2. The website will automatically display it in the About section
3. The image will have a grayscale effect that transitions to color on hover

## Project Screenshots

To add project screenshots:
1. Add images to this folder (e.g., `swastha-preview.jpg`)
2. Update the project data in `data/projects/*.md`
3. Reference images in ProjectCard component if needed
